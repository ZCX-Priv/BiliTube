## 实现计划：B站搜索接口 Cookie 获取（不使用 Playwright）

### 需求调整

1. **Cookie 只对搜索接口生效**：前端搜索请求（`api.bilibili.com/x/web-interface/wbi/search/type`）
2. **不使用 Playwright**：改用其他方案获取真实浏览器 cookie

### 技术要点

**请求头模拟**：
```python
headers = {
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36',
    'Accept': 'text/html,application/xhtml+xml,application/xml;q=0.9,image/avif,image/webp,*/*;q=0.8',
    'Accept-Language': 'zh-CN,zh;q=0.9,en;q=0.8',
    'Accept-Encoding': 'gzip, deflate, br',
    'Connection': 'keep-alive',
    'Upgrade-Insecure-Requests': '1',
    'Sec-Fetch-Dest': 'document',
    'Sec-Fetch-Mode': 'navigate',
    'Sec-Fetch-Site': 'none',
    'Sec-Fetch-User': '?1',
}
```

**Cookie 获取流程**：
1. 访问 `https://www.bilibili.com` 获取基础 cookie
2. 访问主页面触发 cookie 设置
3. 解析响应头中的 Set-Cookie

**搜索接口识别**：
```python
def is_search_api(url):
    return 'api.bilibili.com/x/web-interface/wbi/search/type' in url
```

### 测试验证

1. 启动 `python backend.py`
2. 检查 temp.json 是否生成
3. 通过前端搜索功能测试
4. 验证请求是否携带了 cookie

### 注意事项

1. urllib 方案可能不如真实浏览器完整
2. B站可能检测到非浏览器访问
3. Cookie 可能需要定期更新
4. 登录状态的 SESSDATA 可能无法通过 urllib 获取
